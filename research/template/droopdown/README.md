# Dropdown templates

Open any HTML file directly in a browser. Each example is self-contained and uses native select controls for keyboard and mobile support. The open option menu follows the browser or operating system; CSS styles the closed field.

- CREDENCE_Settings_Dropdown.html: standard settings selection, helper text and disabled state. Source: front/app-next/src/components/dashboard/UploadedTemplatePanel.module.css.
- CREDENCE_Filter_Dropdown.html: compact status and chart filters. Sources: front/app-next/src/app/dashboard/credentials/page.js and components/dashboard/CredentialCharts.module.css.
- CREDENCE_Grouped_Field_Dropdown.html: optgroup selection for editor fields. Source: components/dashboard/UploadedTemplatePanel.js.
- CREDENCE_Navy_Dropdown.html: cream-on-navy variant of the standard field.

Palette: navy #08283F, cream #F8F7F2, maroon #780110. These are selection controls, so they do not use the animated action-button style. Keep visible labels and helper-text associations when reusing them. No API calls or app mutations occur in these examples.
