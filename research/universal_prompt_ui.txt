Design a modern enterprise web application called CREDENCE.

CREDENCE is a blockchain-powered academic certificate issuance and verification platform developed as a proof-of-concept for higher education institutions.

IMPORTANT

This is NOT a University Management System.

The application ONLY manages the lifecycle of academic certificates.

Its responsibilities include:

• Certificate issuance
• Certificate management
• Certificate storage
• Blockchain registration
• Certificate verification
• QR verification
• Certificate audit history

The application does NOT manage:

• Student admissions
• Course registration
• Finance
• Examinations
• Timetables
• Learning Management
• General student records

The blockchain is the trust layer.

The university issues certificates, but certificate authenticity is verified through blockchain records rather than relying solely on a centralized database.

SYSTEM USERS

Design all interfaces around these roles.

• Super Admin
• Institutional Admin
• Registrar
• Student
• Employer / Verifier

Each interface should expose only the features relevant to that role.

DESIGN PHILOSOPHY

The application should communicate:

Trust

Security

Academic Excellence

Professionalism

Transparency

Simplicity

Modern Enterprise Software

The design should resemble enterprise platforms such as Stripe Dashboard, GitHub, Linear, Microsoft, Atlassian, and Notion rather than cryptocurrency exchanges or NFT marketplaces.

Avoid flashy Web3 aesthetics.

Blockchain should remain mostly invisible while providing trust behind the scenes.

DESIGN STYLE

Create a clean and spacious interface with:

• Large whitespace
• Comfortable spacing
• Soft shadows
• Rounded corners
• Minimal borders
• Clear hierarchy
• Consistent alignment
• Low visual noise

The interface should reduce eye strain during prolonged use.

OVERALL EXPERIENCE

Every page should feel like a polished enterprise product used by universities and government institutions.

The interface should inspire confidence, reduce cognitive load, and clearly communicate that academic certificates are secured by blockchain technology while keeping blockchain in the background.

Users should immediately perceive CREDENCE as a trusted institutional certificate platform rather than a cryptocurrency application.

Maintain consistency in layout, spacing, typography, colors, navigation, and component design across all pages so the application feels cohesive, scalable, and production-ready.
